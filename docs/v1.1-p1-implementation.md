# LOADS v1.1 P1 実装記録

追記（2026-10-14）: 新版の分類付き受信・表示に対応し、形式検証と送信停止を分離した。送信停止は継続。全テスター最新版方針と解禁条件は `v1.1-classified-feed-readiness.md` を参照。以下の190件結果と受信制限の記述は前段階の実装記録。

## 実装した仕様

- `pr.ts`で画面・履歴・投稿のPR判定を共通化。v1の初回PR・未経験重量REP PR・0反復重量PRを含む旧挙動は維持。旧ライブ画面の同名複数ブロックVOLUME比較の差もcontextで維持する。
- WorkoutSession / ActiveWorkoutに任意のprVersion。欠落はv1。新規開始・テンプレート開始はv2。旧進行中記録はv1で再開・終了する。
- v2は実施1回以上の完了セットのみPRに使用。failed / stoppedでも実施反復を保持。0反復は保存できるがPR・初回基準には使わない。
- 通常種目は最大重量更新、同重量での反復数更新。未経験重量REP PRなし。VOLUMEはVOLUMEモード間のブロック比較。初VOLUMEは基準確立のみ。
- FIRST RECORDは独立した状態。新ライブ画面・履歴・投稿プレビュー・フィードに中立の枠付き表示。prCountは既存の3種PRの合計のまま。
- PULL UPのみassisted / bodyweight / weightedを種目レベルで保存。既存未分類記録を分類しない。分類同士・未分類との比較を分離。
- ASSISTEDは補助重量の過去最小値更新がWEIGHT PR。40kg x 8 → 30kg x 1でもPR。同補助重量で反復更新がREP PR。自重は反復のみ、加重は追加重量のみ。
- 自重・補助はvolume=0として集計から除外し、画面に除外を明記。VOLUME PR無効。加重VOLUMEは追加重量 x 実施反復。
- 分類はアクティブ復元・終了保存・テンプレート保存/開始・前回セット呼び出し・履歴・コピーに引き継ぐ。旧PULL UPテンプレートを新規開始した場合は明示分類が必要。
- 新規v2投稿の判定メタデータはexercises JSONB内の任意prVersion / recordStatus。新カラム・RLS変更は不要。既存・送信待ち投稿は再計算しない。

## 分類付き投稿を停止した理由と安全策

v1 FeedPostCardは分類フィールドを知らず、bestWeightを常にkg x repsで表示する。種目メモも表示しないため、メモによる互換表示は保証できない。補助値を通常重量として表示したり、自重の負荷を0kgとして扱わせる可能性がある。

分類付き種目を含むワークアウト全体の新規投稿は停止した。種目を勝手に除去した投稿や値を偽装した投稿は作成しない。投稿画面で理由を表示して送信ボタンを無効化し、handlePostとvalidatePostにも防御を入れ、outbox書込み・写真アップロード・posts INSERTより前に拒否する。

通常種目・旧未分類PULL UP・既存送信待ち投稿は引き続き投稿/再送可能。分類付き記録は履歴とコピーで共有できる。分類付き投稿を再開するには旧クライアント表示に対する別の互換契約、または利用可能なクライアントのバージョン制限を設計・承認する必要がある。
