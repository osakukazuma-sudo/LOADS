# LOADS

LOADS is a workout logging app built with React Native and Expo.

## Concept

No flex, just work.

トレーニング記録を簡単に残し、
前回の重量や自己ベストをすぐ確認できることを目的に開発しています。

## Features

- ワークアウト記録
- 種目ごとの重量・回数・セット数の保存
- 前回トレーニング内容の確認
- 履歴表示
- プロフィール画面
- PR管理

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
